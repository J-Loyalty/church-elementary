# 주일 예배 순서 만들기 (자동 생성 도구)

매주 아이들과 학부모님께 전하는 초등부 **주일 예배 순서 안내지**를 이미지로 만드는 도구입니다.
[주일 예배 순서 도구](../web/worship-order.html)(`web/worship-order.html`)를 브라우저로 열어 몇 칸만 채우면 완성된 이미지(PNG)로 저장하거나 바로 인쇄할 수 있습니다.

## 사용 방법

1. `web/worship-order.html`을 더블클릭해서 브라우저로 엽니다. (별도 설치·인터넷 연결 필요 없음)
2. 왼쪽에서 **매주** 바뀌는 항목을 채웁니다.
   - 날짜, 인도자(선생님 목록에서 고르기), 대표기도, 성경봉독, 말씀선언(설교 제목), 헌금·헌금기도
   - 말씀선언은 **한 줄이어도 되고, 줄바꿈해서 두 줄**로 넣어도 됩니다. 줄 수에 맞춰 자동으로 가운데 정렬됩니다.
3. **월 1회**만 바뀌는 항목은 그 달에 한 번만 바꿔주면 됩니다.
   - 찬송가 번호, 2부 순서
   - **주기도문 / 축도** — 평소에는 주기도문, 월말에는 축도로 바꿔 쓰세요. 담당자는 그대로 두고 항목 이름만 바뀝니다.
4. 표어·교회명·담당 교역자·연락처처럼 **거의 바뀌지 않는 정보**는 "고정" 칸을 펼쳐서 필요할 때만 손보세요.
5. 오른쪽에 결과가 바로 보입니다. 위쪽의 **⬇️ 이미지 저장**을 누르면 PNG 파일로 내려받고, **🖨️ 인쇄**를 누르면 인쇄(또는 PDF로 저장)할 수 있습니다.
6. **다음 주일 날짜로** 버튼을 누르면 날짜가 다음 주일로 넘어갑니다.

## 알아두면 좋은 점

- 입력한 값은 그 컴퓨터의 브라우저에 저장됩니다(밖으로 전송되지 않습니다). 다음 주에 다시 열면 지난 내용이 남아 있어, 바뀐 칸만 고치면 됩니다.
- 인터넷 연결 없이 `worship-order.html` **파일 하나만으로** 동작합니다. 배경 사진이 파일 안에 들어 있어서 다른 파일을 함께 옮기지 않아도 됩니다.
- 배경에는 하늘·구름 사진과 동그란 자리만 들어 있고, 표어·제목·연락처·날짜·예배 순서는 **전부 이 도구가 그때그때 얹어서 그립니다.** 그래서 표어부터 담당자까지 모두 바꿀 수 있습니다.
- 글자 위치와 색·카드 모양은 실제로 쓰던 주보를 그대로 재보고 맞췄습니다.

## 배경 사진을 바꾸려면

`web/assets/images/worship-order-bg.png`는 편집용 원본입니다. 실제로 쓰이는 것은 `web/worship-order.html` 안에 들어 있는 복사본이라, 사진을 바꾸려면 두 단계가 필요합니다.

1. `web/assets/images/worship-order-bg.png`를 새 사진으로 바꿉니다. (같은 파일 이름, 891×1260 크기 권장 — 크기나 구도가 많이 달라지면 `web/worship-order.html` 안의 위치 값도 함께 맞춰야 합니다.)
2. **저장소 맨 위 폴더**에서 아래 명령을 실행해 새 사진을 `web/worship-order.html`에 다시 넣습니다.

```bash
python3 -c "import base64,re; b=base64.b64encode(open('web/assets/images/worship-order-bg.png','rb').read()).decode(); h=open('web/worship-order.html',encoding='utf-8').read(); open('web/worship-order.html','w',encoding='utf-8').write(re.sub(r'data:image/png;base64,[^\"]+','data:image/png;base64,'+b,h))"
```

> 사진을 파일 안에 넣지 않고 바깥 파일로 불러오면, 브라우저에 따라 이미지 저장이 막히는 경우가 있어(캔버스 보안 제한) 이렇게 넣어 둡니다.
