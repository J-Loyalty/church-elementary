# 초등부 연간 계획

한 해 동안 초등부가 어떤 흐름으로 움직이는지 **연도별로 모아 둡니다.** 해마다 이 폴더에 그해 계획을 더해 갑니다.
행사별 자세한 진행은 [기획안](../기획안/README.md)을, 살림(예산)은 [예산](../예산/README.md)을 함께 보세요.

## 해마다 이어지는 흐름

- **성경 읽기(또는 쓰기)** — 연 3회, 회당 8주 또는 12주 과정으로 스스로 말씀 읽는 습관을 기릅니다. → [성경 읽기 기획안](../기획안/성경-읽기.md)
- **생일자 축하와 레크레이션** — 매월 진행합니다. 월별 생일자 명단은 개인정보라 문서에 담지 않고 **별도 구글 시트로 관리**합니다.
- **토요 활동** — 예전 ‘모여라 토요일’의 취지(관계·신앙 리듬)를 이어, 지금은 눈썰매장·체육대회·문화행사 등의 이름으로 진행합니다. → [지난 시도에서 배운 것](../논의/지난-시도에서-배운-것.md)

## 함께 논의 중인 아이디어

연간 계획을 세우며 나온, 앞으로 시도해 볼 만한 것들입니다. (확정 아님)

- 찬송가 음이 높을 경우 아이들이 부르기 좋게 **키를 낮춰** 부르기
- **매월 마지막 주** 축도 후, 피아노 반주와 함께 짧은 **묵상 시간(약 20~30초)** 을 더하기
- 분기나 학기별로, 설교자가 **성경 속 인물로 분장**해 말씀을 전해 분위기를 새롭게 하기
- 레크레이션 시간에도 아이들이 **성경 속 인물로 분장**해 참여하는 프로그램 해 보기
