# 2026 초등부 연간 계획

2026년 한 해의 월별 활동 흐름입니다. (해마다 공통으로 이어지는 흐름은 [연간 계획 안내](README.md) 참고)

> 💡 매월 **생일자 축하와 레크레이션**이 함께 진행됩니다. 월별 생일자 명단은 개인정보라 별도 구글 시트로 관리합니다.

---

## 월별 흐름

| 시기 | 주요 활동 |
| --- | --- |
| 1월 | 1학기 공과 시작 · 신입생 환영회(첫째 주) · 학부모 간담회 |
| 2월 | 토요 활동 — 눈썰매장(겨울 성경학교 대체) · **성경 읽기 8주 과정 시작** |
| 3월 | 학생 심방(전체 학년) · (초등학교 1학기 개학) |
| 4월 | 토요 활동 — 체육대회 · **상반기 달란트 잔치**(셋째 주) · 부활절 |
| 5월 | 황동노회 그림·글짓기 대회 · 어린이주일 · 어버이주일(학부모 초청 예배·간담회) · 스승의 주일 |
| 6월 | 여름 성경학교 준비 · **성경 읽기 12주 과정** |
| 7월 | **여름 성경학교(1박 3일)** |
| 8월 | 2학기 공과 시작 · 문화 행사 |
| 9월 | **하반기 달란트 잔치**(셋째 주) · **성경 읽기 8주 과정** · (초등학교 2학기 개학) |
| 10월 | 토요 활동 · 학생 심방(성탄 전야 준비 겸) · 교사 야유회(월말) |
| 11월 | 성탄 전야 행사 준비 |
| 12월 | 성탄 전야 행사 · 성탄절 · 졸업예배 · 연말 시상(달란트·개근·정근·전도) |

- 공과는 **하나바이블 1과정**으로 상반기를 진행하고, 여름 성경학교 이후 **2과정**으로 이어집니다.
- 하반기 달란트 잔치는 예년에 10월에 하던 것을 **2026년에는 9월 셋째 주**로 진행합니다.
