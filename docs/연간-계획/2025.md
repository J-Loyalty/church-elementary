# 2025 초등부 진행 기록

2025년 한 해 동안 실제로 진행한 활동 기록입니다. (지난해 자료 보관용)
매월 **생일자 축하와 레크레이션**이 함께 진행됐으며, 그달의 레크 종류를 괄호로 적었습니다.

---

## 월별 진행

| 시기 | 진행한 활동 |
| --- | --- |
| 1월 | 생일자 축하·레크레이션(판 뒤집기 게임) |
| 2월 | 모여라 토요일 — 눈썰매장(겨울 성경학교 대체) · 레크(그림 그리기·만들기) |
| 3월 | 성경 읽기 시작(스토리) · 3·6학년 전체 심방 · 레크(그림 그리기·만들기, 캐치마인드) |
| 4월 | 모여라 토요일 — 봄 소풍 대체 · 상반기 달란트 잔치 · 교사 세미나 · 1·2·4·5학년 전체 심방 · 레크(캐치마인드) |
| 5월 | 황동노회 그림·글짓기 대회 · 질서에 대한 강의 |
| 6월 | 레크(릴레이 장애물 스포츠) |
| 7월 | 여름 성경학교(주제 강습회·교사 강습회 포함) · 레크(여름 성경학교 퀴즈) |
| 8월 | 교사 회식 · 영화 관람(King of Kings) · 레크(피구) |
| 9월 | 성경 읽기 시작(잠언) · 하반기 달란트 잔치(27일 토) · 레크(지시대로 판 뒤집기) |
| 10월 | 추석 명절 레크레이션(성경인물 빙고게임) |
| 11월 | 생일자 축하·레크레이션 |
| 12월 | 성탄 전야 행사 준비 · 성탄 전야 행사·성탄절 · 졸업예배 · 연말 시상(달란트·개근·정근·전도) |

- 2025년에는 토요 활동을 **‘모여라 토요일’**이라는 이름으로 진행했습니다. (지금은 그 이름 대신 눈썰매장·체육대회·문화행사 등으로 이어감 → [지난 시도에서 배운 것](../논의/지난-시도에서-배운-것.md))
- 공과는 성경 쓰기·성경 읽기와 함께 진행했고, 이후 하나바이블 교재 흐름으로 이어졌습니다.
