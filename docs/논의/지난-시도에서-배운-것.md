# 지난 시도에서 배운 것

과거에 시도했다가 지금은 하지 않는 프로그램과, 멈춘 이유·거기서 얻은 교훈을 기록합니다.
**실패가 아니라 배움**입니다. 개인 경건·지속 목양을 다시 세울 때 같은 함정을 피하도록 남겨둡니다.
→ [신앙 중심 운영 점검](신앙-중심-운영-점검.md)의 ③·④와 연결됩니다.

---

## 1. QT책 연간 구독 50% 지원

| 항목 | 내용 |
| --- | --- |
| 무엇 | QT책 연간 구독료의 50%를 초등부 재정으로 지원 |
| 겨눈 목표 | 개인 경건·말씀 습관 (점검 ③) |
| 멈춘 이유 | 참여 인원이 적었고, "하는 아이들만 부서 재정 혜택을 받아 **불공평**하다"는 의견이 일부 나옴 |

**배운 것 / 다시 한다면**
- 형평성 지적의 본질은 *QT 자체*가 아니라 **'일부만 재정 지원'이라는 선택적 구조**였습니다.
- 대안 ⓐ **전원에게 열기** — 원하는 누구나 저비용/무료로 참여
- 대안 ⓑ **돈이 들지 않는 형태로** — 공과·[성경 읽기](../기획안/성경-읽기.md)와 묶어 "함께 읽기" 문화로
- 근본적으로는 **부서 재정 형평성 기준**(어디까지 공평하게 쓸 것인가)을 정해두면 이런 결정이 쉬워집니다.

---

## 2. 모여라 토요일

| 항목 | 내용 |
| --- | --- |
| 무엇 | 2주마다 토요일에 모여 진행하던 모임 |
| 겨눈 목표 | 지속적 관계·신앙 리듬 (점검 ④) |
| 멈춘 이유 | 그 시간을 할애할 교사가 없었음 |

**배운 것 / 다시 한다면**
- 진짜 교훈은 **지속가능성**입니다. 무리하게 끌고 가지 않고 멈춘 것은 현명한 판단이었습니다.
- 목표(관계·리듬)를 살리되 가볍게 — 빈도↓(**학기 1~2회**), 별도 모임 대신 **이미 있는 토요일 활동([반별 심방](../기획안/반별-심방.md) 등)에 흡수**, 한 명 전담 대신 **순번제**.
- **지금은** ‘모여라 토요일’이라는 이름으로 운영하지는 않지만, **같은 취지(관계·신앙 리듬)를 살려 토요 활동(눈썰매장·체육대회·문화행사 등)으로 이어가고 있습니다.** → [연간 계획](../연간-계획/README.md)

---

## 3. 공통 교훈

- 두 프로그램 모두 **방향(개인 경건·관계)은 옳았고**, 문제는 형태였습니다. **필요는 지금도 남아 있습니다.**
- 두 경험에서 얻은 **「형평성」과 「지속가능성」** 은, 앞으로 새 프로그램을 만들 때 좋은 잣대가 됩니다.
  - 이 프로그램은 **모두에게 공평한가?**
  - 이 프로그램은 **무리 없이 계속할 수 있는가?**
