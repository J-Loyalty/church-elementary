# 초등부 예산

초등부 한 해 살림(수입·지출)을 **연도별로 모아 둡니다.** 재정은 **회계(조남선 권사)**가 관리하며, 해마다 이 폴더에 그해 예산을 더해 갑니다.

## 연도별 예산

| 연도 | 문서 |
| --- | --- |
| 2026 | [2026 예산](2026.md) |
| 2025 | [2025 예산·결산](2025.md) |

## 회계 실무 (해마다 공통)

- **수입** — 교회 지원금(교회 본 재정에서 배정) + 후원·찬조 + 회비 + 전년 이월금으로 마련합니다.
- **회비 기준** — 기본 회비와 여름 성경학교 회비가 있습니다. (금액은 연도별 문서 참고)
- **심방비 지원** — 심방 시 학생 1인당 정액(2026년 1인 10,000원)을 지원하며, 인원수에 따라 변동됩니다.
- **교사 회식(교육)** — 교사 1인당 정액(2026년 2만원)으로 연 2회 진행합니다.
- **지출·정산** — 지출과 영수증 정리, 잔액·이월금 관리는 회계를 통해 진행합니다.
- **민감정보는 여기 두지 않습니다** — 계좌번호·영수증·회비 납부 현황 등은 별도 구글 시트와 교회 회계로 관리합니다. 📝 인수인계 시 회계 담당과 시트 접근 권한을 함께 넘겨주세요.
