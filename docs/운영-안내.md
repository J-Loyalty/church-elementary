# 초등부 운영 안내

김포남현교회 초등부를 섬기는 교사와 봉사자를 위한 운영 안내 문서입니다.
조직, 반 편성, 찬양팀, 주일 일정과 주간 준비 흐름을 정리했습니다.

---

## 1. 조직 및 역할

| 직분 | 이름 | 역할 |
| --- | --- | --- |
| 담당 교역자 | 김진서 목사 | 말씀 설교, 부서 전체 목양과 방향 |
| 부장 | 장충성 집사 | 부서 운영 총괄, 교사 관리 |
| 회계 | 조남선 권사 | 재정·회계 관리, 간식 |
| 반사(교사) | 반별 담임교사 → [2. 반 편성](#2-반-편성) | 분반공부 인도, 학생 심방과 관리 |
| 찬양팀 | → [3. 찬양팀](#3-찬양팀) | 예배 찬양 인도 및 반주 |

---

## 2. 반 편성

유년부 4개 반, 초등부 4개 반으로 편성합니다. 반 이름은 **성경(갈라디아서 5:22~23)의 성령의 9가지 열매** 중에서 **뽑기로 결정**합니다.

| 부서 | 반 | 담임교사 |
| --- | --- | --- |
| 유년부 | 기쁨 | 이선미 집사 |
| 유년부 | 절제 | 김옥주 집사 |
| 유년부 | 신실 | 박미월 집사 |
| 유년부 | 사랑 | 서옥래 집사 |
| 초등부 | 친절 | 조소현 집사 |
| 초등부 | 선함 | 박미경 집사 |
| 초등부 | 온유 | 박종렬 장로 |
| 초등부 | 인내 | 장충성 집사 · 이수진 집사 |

- 예배는 **유년부 → 초등부 순서**로 진행합니다.
- 예배 봉사 순번(인도·대표 기도·헌금위원)도 이 순서를 따릅니다. → [예배 안내 – 예배 봉사 순번](예배-안내.md#2-예배-봉사-순번-반별-순환) 참고

## 4. 주일 일정

| 시간 | 일정 |
| --- | --- |
| 11:00 ~ 12:10 | 예배 |
| 12:10 ~ 12:30 | 공과공부 (분반) |
| 12:30 ~ 13:00 | 점심 식사 (식당) |
| 13:05 ~ 14:00 | 초등부 회의 (결석자·특이사항·회의 내용 나눔) |

- **교사**는 오전 **2부 예배(09:30)** 로 자신의 예배를 드린 뒤, **11시부터 초등부에서 섬깁니다.**
- **월말(마지막 주)** 에는 앉아서 하는 공과 대신, 그날 공과 내용을 활동적으로 나누는 전체 레크레이션(활동형 공과)을 진행합니다. → [활동 안내](활동-안내.md#5-월말-활동-마지막-주) 참고

## 5. 주간 준비 흐름

**주중 ~ 주말**
- 학생들은 각자 삶 속에서 한 주를 보냅니다.
- 주말에 다음 주일을 준비하며 아래를 진행합니다.
  - **주일 예배 순서지 전달** (그 주 담당 반의 봉사 순서 안내)
  - **암송 전달** (이 주의 암송 말씀)
  - **참석 여부 조사**

**주일 예배 전**
- 교사 기도회 참석
- 예배 환경 및 자료 점검
- 학생 맞이 및 출석 준비

**주일 예배 후**
- 분반공부 인도
- 출석·새친구 정리
- **초등부 회의 (오후 1:05~2:00)** — 결석자, 특이사항, 회의 내용을 함께 나눔

## 6. 참고 사항

- **소통 창구** — 카카오톡을 이용합니다.
- **행사 신청** — 행사 참석 신청은 **구글 폼**으로 받습니다. 보통 **3주 전 발송 → 2주 전 집계**(늦을 경우 1주 전까지)로 진행합니다. (단, **반별 심방은 반별 카카오톡 단체방**으로 진행)
- **결석 관리** — 주중 또는 주일 예배 후 바로 결석 아동을 심방합니다. 대부분 담당 교사가 진행하며, 필요한 경우 사역자 또는 부장이 직접 심방하기도 합니다.
- **새친구 관리** — 등록·환영·정착을 돕습니다. (예배 중 새신자 축하 → [활동 안내](활동-안내.md#2-예배-중-진행하는-활동-광고-시간) 참고)
- **안전 관리** — 별도의 안전 수칙은 없으며, 예배실 CCTV를 상시 운영합니다.
