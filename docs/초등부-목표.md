# 초등부 목표

부장의 관점에서 세운 초등부의 목표입니다. **아이가 초등부를 졸업할 때까지 이런 모습으로 자라기를** 바랍니다.
예배·공과·활동·기획은 모두 이 목표를 섬기기 위한 것입니다. 판단이 필요할 때 **"이것이 이 목표에 도움이 되는가?"** 로 돌아봅니다.

---

## 목표

1. **성경책으로 성경과 찬양을 찾을 수 있다.**
2. **매주 진행되는 암송 구절 중 하나라도, 졸업할 때 암송해 나갈 수 있다.**
3. **예수님의 성품을 닮아간다.**
4. **감사의 삶을 산다.**
5. **교회에 오는 것이 즐겁다.**
6. **초등부 친구들과 사이좋게 지낸다. (1~6학년이 골고루)**

---

## 세 갈래로 보면

| 갈래 | 목표 | 한마디 |
| --- | --- | --- |
| **말씀** | 1 · 2 | 스스로 말씀을 찾고, 마음에 새긴다 |
| **성품·삶** | 3 · 4 | 예수님을 닮고, 감사로 산다 |
| **공동체** | 5 · 6 | 교회가 즐겁고, 친구와 사이좋다 |

머리(알고) · 가슴(사랑하고) · 삶(살아가고)이 고르게 담긴 목표입니다.

---

## 목표와 현재 활동의 연결

각 목표가 실제 어떤 활동으로 자라고 있는지입니다.

| 목표 | 이를 섬기는 활동 |
| --- | --- |
| 1. 성경·찬양 찾기 | 예배 성경 봉독(직접 펴기), 찬송가, 공과 |
| 2. 암송 | 매주 암송·성경 퀴즈, 달란트, 성경 읽기 |
| 3. 예수님의 성품 | 설교·공과, 반 이름(성령의 아홉 열매), 칭찬 달란트 → [공과에 성품·교리 녹이기](논의/공과-성품-교리-녹이기.md) |
| 4. 감사의 삶 | 예배 감사 헌금, 달란트 잔치의 감사·선교·구제 헌금 |
| 5. 교회의 즐거움 | 레크레이션(활동형 공과), 달란트 잔치, 연간 행사, 생일 축하 |
| 6. 친구와 사이좋게 (1~6학년) | 반별 활동·심방, 전체 레크레이션, 여름 성경학교, 전체 행사 |
