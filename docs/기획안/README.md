# 초등부 활동 기획안

연간 행사·정기 활동별 상세 기획안을 모아둔 폴더입니다.

- 각 기획안은 매년 반복되는 행사의 **재사용 템플릿**입니다.
- 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝` 표시를 채우거나 갱신해 사용하세요.
- **행사 신청**은 구글 폼으로 받습니다. 보통 **3주 전 발송 → 2주 전 집계**(늦을 경우 1주 전까지)로 진행합니다. (단, **반별 심방**은 반별 카카오톡 단체방으로 진행)
