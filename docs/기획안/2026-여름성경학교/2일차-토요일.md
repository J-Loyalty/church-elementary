# [2026 여름성경학교] 2일차 — 7월 25일(토)

둘째 날 상세 진행표입니다. 아침 예배·2과 → **김포조각공원 물놀이** → 귀가 흐름입니다.

> 미확정·확인이 필요한 항목은 문서 맨 아래 [확인·미정 사항](#3-확인미정-사항)에 모아 두었습니다.
>
> **개인 준비물**(물놀이 용품·세면도구·여벌 옷 등)은 별도 **가정통신문**으로 안내되었습니다.
>
> **인원(식사·간식 기준)** — 아이 50명 + 어른 20명 = **총 70명분** *(당일 물놀이 참석 인원에 따라 조정)*
>
> **PPT·장비** — 빔·스크린·음향은 비전센터 2층 상시 구비. **2과 예배 PPT는 제작 필요**.

- **짐 이동** — 개인 짐을 **본당 성가대실**로 옮겨 보관합니다.

### 준비찬양 (8:00 ~ 8:15)

- 설교 중 교사들은 **공과 자리로 이동해 대기**(쉬는 타임)

### 2과 공과 (8:35 ~ 9:30)

### 물놀이 (10:00 ~ 14:00, 점심 포함)

**진행 체제** — 아버님(물 안, 아이들과 놀기) + 여교사(뭍에서 운영·안전 지원) 이원 체제. **전체 총괄: 장충성 집사**.

#### 타임 운영 (50분 놀이 / 10분 휴식)
- 10:00~10:50 **1차** → 10:50~11:00 휴식(간식·수분·**반별 인원 확인**·화장실)
- 11:00~11:50 **2차** (**서옥래 집사 11:30 김밥 픽업 이탈**) → 11:50~12:00 정리
- 12:00~13:00 **점심(김밥)** — 준비: 조남선 권사
- 13:00~13:50 **3차** → 13:50~14:00 정리
- ※ **입·퇴수는 물놀이장 안전요원·방송 신호**에 따름 (별도 교사 신호 없음)

#### 인력 배치
- **전체 총괄** — **장충성 집사** (안전요원·아버님 소통, 반별 인원 취합, 현장 판단)
- **물 안·물가 (남성)** — 아버님 10 + 김진서 목사·박종렬 장로·김동완 학생 → **팔찌 찬 아이 전원 공동 케어**
- **뭍 스테이션 (여교사 8 + 어머님 1)** — 휴식 10분마다 **로테이션**

| 스테이션 | 1차 | 2차 | 3차 |
| --- | --- | --- | --- |
| 총괄·순회 안전 (고정) | 이유진·조소현(구급함) | ← | ← |
| 베이스캠프(짐+간식·수분) | 박미경·박미월 | 김옥주·이선미 | 이수진·김재원 |
| 여아 케어·화장실 | 이수진·김재원 | 박미경·박미월 | 김옥주·이선미 |
| 매점 대기·케어 | 김옥주·이선미 | 이수진·김재원 | 박미경·박미월 |

- **베이스캠프** = 짐·귀중품 + 간식·수분 통합 / **매점 대기** = 쉬며 매점에 온 아이 케어
- **인원 카운트** — 각 반 담임이 휴식·타임 경계마다 **자기 반** 확인 → 장충성 집사 취합
- **어머님 1명** — 여아 케어 합류

#### 🎗️ 팔찌 (물놀이용 별도 띠)
- 우리 아이 = **띠 착용** → 팔찌 찬 아이는 어른 누구든 **"보이는 대로 공동 케어"**
- **브리핑**(출발 전/도착 직후) — 어른: "띠 찬 아이는 모두 우리 아이" / 아이: "띠 빼지 않기 · 화장실·매점은 어른에게 말하고 · 힘든 친구 보면 알리기"

#### 🚿 샤워 (14:00 ~ 14:30)
- **남아: 아버님 + 남성 인력 / 여아: 여교사 8 + 어머님 1** · 베이스캠프 1명은 짐 지킴 유지

- **간식** — 아이들이 물에서 나올 때: 젤리, 1인 음료, 물 350㎖(얼음), 컵라면(매점)
- **비용** — 물놀이 비용은 **초등부 재정으로 지원**합니다.
- **안전** — 교사 + 학부모(아버님) 공동 인솔 + **물놀이장 자체 안전요원** 배치.
- **도우미 요청** — 초등부 아버님들께 요청 완료(이인호·이정록·윤정민 집사 등) · **당일 참석·차량봉사 3분 확인 필요**
- **준비물** — ☐ **물놀이용 띠(+여분)** ☐ 물놀이 간식 ☐ 상비약 ☐ 돗자리(큰 것) ☐ 여분의 수건 ☐ 네임펜 ☐ 견출지 ☐ 네임텍 *(모자·물놀이 가방(큰 것)은 개인 지참 — 개인 준비물)*

## 3. 확인·미정 사항

- [ ] **물놀이 도우미 당일 참석 확인** — 초등부 아버님들께 요청 완료, 당일 실제 참석자 확인 필요
- [ ] **차량봉사 아버님 3분 실명 확정** — 봉사①(7인승)·②③(5인승). 봉사차엔 아이만 탑승, 학부모는 교회차 우선
- [ ] **25인승 버스 대형면허 확인** — 김진서 목사 운전 예정. 1종 대형 미소지 시 기사 섭외 필요
- [x] **물놀이 인력배치·팔찌·배차 확정** — 총괄 장충성 / 물 안 아버님·남성 / 뭍 여교사 로테이션(베이스캠프·여아케어·매점) / 팔찌(별도 띠) 공동 케어 / 배차 8대(+예비 2)로 정리 (상세 위 슬롯 참고)
- [x] **물놀이 모자** — 개인 지참으로 결정 (가정통신문 개인 준비물로 안내)
- [x] **귀가 햄버거** — 미지급으로 확정
- [x] **우천·폭염 대책** — **폭염**: 별도 그늘/텐트 확보 + 물놀이장 자체 그늘, 물놀이 중 수분 보충 타임 운영. **우천**: 소나기 수준(현 예보 0.6㎜)이면 진행하되, **뇌우·낙뢰 또는 폭우 시 취소**(물+번개는 강수량 무관 무조건 중단). **토요일 아침 8시 최종 판단 → 학부모 단톡 즉시 공지 + 김밥·픽업(서옥래 집사) 취소**. 취소 시 **2과 예배·공과까지만 하고 조기 귀가**(교회 실내는 같은 날 유치부 여름성경학교 사용으로 대체 불가)
- [x] **물놀이 안전** — 교사 + 학부모 공동 인솔, 물놀이장 **자체 안전요원** 배치 (→ [템플릿 안전 관리](../여름-성경학교.md#6-안전-관리))
