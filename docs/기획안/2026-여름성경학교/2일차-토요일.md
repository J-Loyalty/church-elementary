# [2026 여름성경학교] 2일차 — 7월 25일(토)

둘째 날 상세 진행표입니다. 아침 예배·2과 → **김포조각공원 물놀이** → 귀가 흐름입니다.

> 미확정·확인이 필요한 항목은 문서 맨 아래 [확인·미정 사항](#3-확인미정-사항)에 모아 두었습니다.
>
> **개인 준비물**(물놀이 용품·세면도구·여벌 옷 등)은 별도 **가정통신문**으로 안내되었습니다.
>
> **인원(식사·간식 기준)** — 아이 50명 + 어른 20명 = **총 70명분** *(당일 물놀이 참석 인원에 따라 조정)*
>
> **PPT·장비** — 빔·스크린·음향은 비전센터 2층 상시 구비. **2과 예배 PPT는 제작 필요**.

## 2. 슬롯별 세부

### 선생님 집합 (~ 7:00)
- 선생님 교회로 집합

### 기상·세면·자리 정리·아침 식사 (7:00 ~ 8:00)
- **아침 메뉴** — 시리얼, 모닝빵, 우유·두유·락토프리, 요거트, 딸기잼·포도잼, 컵라면
- **기상 후 복장** — 수영복 + 성경학교 티셔츠 (물놀이 대비)

### 준비찬양 (8:00 ~ 8:15)
- **담당** — 이유진 사모, 지수민 학생, 김동완 학생(방송실), 김재원(이수진 집사 자녀, 27)
- **준비물** — ☐ 2과 예배 PPT

### 2과 설교 (8:15 ~ 8:45)
- **담당** — 김진서 목사
- 설교 중 교사들은 **공과 자리로 이동해 대기**(쉬는 타임)

### 2과 공과 (8:45 ~ 9:30)
- **담당** — 반별 담임교사 / **준비물** — ☐ 각 반 공과 자료
- 공과를 **마치는 대로 초등부실로 이동**
- ※ **신실반** 담임 부재 → **장충성 집사** 대체 진행

### 이동 — 물놀이장 (9:30 ~ 10:00)
- 9:30 버스·스타렉스 탑승 (**명단 정리**)
- 9:40 ~ 10:00 김포조각공원 물놀이장으로 이동

### 물놀이 (10:00 ~ 14:00, 점심 포함)
- **점심** — 김밥 (픽업: 서옥래 집사)
- **자리 맡기** — 수영장에 들어가지 않는 선생님들이 자리 확보
- **간식 챙겨주기** — 아이들이 물에서 나올 때: 젤리, 1인 음료, 물 350㎖(얼음), 컵라면(매점)
- **도우미 요청** — 저학년 아버님들 → 이인호 집사·이정록 집사·윤정민 집사 *(가능 여부 확인 중)*
- **진행·안전** — 교사 + 학부모가 함께 인솔하며, **물놀이장 자체 안전요원**이 배치되어 있습니다.
- **준비물** — ☐ 물놀이 간식 ☐ 상비약 ☐ 돗자리(큰 것) ☐ 여분의 수건 ☐ 네임펜 ☐ 견출지 ☐ 네임텍 ☐ 물놀이 가방(큰 것) ☐ 모자(야구모자 또는 수영모자)

### 샤워·환복·귀가 (14:00 ~ )
- 14:00 ~ 14:30 샤워 및 일상복 환복
- 14:30 ~ 14:40 교회로 이동 준비 → 14:40 ~ 15:10 교회로 이동
- **귀가** — 햄버거 제공 시 바로 차량 탑승 또는 먹고 탑승 *(제공 여부 검토 중 — 진행 시 **롯데리아 버거 사전 주문·픽업** 필요)*

## 3. 확인·미정 사항

- [ ] **물놀이 도우미 확정** — 이인호·이정록·윤정민 집사 가능 여부 확인 중
- [ ] **모자 준비** — 야구모자 또는 수영모자 (인원수만큼)
- [ ] **귀가 햄버거 여부** — 제공 검토 중. 진행 시 **롯데리아 버거 사전 주문·픽업** 필요
- [ ] **우천·폭염 대책** — 야외 물놀이 일정의 기상 대비책 미비. 우천 시 대체 일정(실내 활동·조기 귀가 등), 폭염 시 그늘·수분 보충·물놀이 시간 조정 기준을 미리 정해두기
- [x] **물놀이 안전** — 교사 + 학부모 공동 인솔, 물놀이장 **자체 안전요원** 배치 (→ [템플릿 안전 관리](../여름-성경학교.md#6-안전-관리))
