첫째 날 상세 진행표입니다. 접수부터 취침까지의 흐름과 슬롯별 담당·장소·준비물을 정리했습니다.

> 미확정·확인이 필요한 항목은 문서 맨 아래 [확인·미정 사항](#4-확인미정-사항)에 모아 두었습니다.

>
> **인원(식사·간식 기준)** — 아이 50명 + 어른 20명 = **총 70명분**

> **PPT·장비** — 빔·스크린·음향(마이크)은 비전센터 2층 **상시 구비**. 준비찬양·개회예배·1과 예배·환영/안내 **PPT는 제작 필요**입니다.

## 2. 슬롯별 세부

### 교사 모임 (~ 15:30)
- **15:00** 차량 운행 시작 → **15:30** 교회 도착
- 기도회 및 아이들 맞이 준비
- 교사 **8명** 참석 가능

### 접수·환복·짐 정리·간식 (15:30 ~ 16:10)
- **흐름** — 1층에서 접수 + 티셔츠·입장팔찌 지급 → 환복 후 2층으로 이동
- **짐** — 2층: 여자아이 / 3층: 남자아이
- **간식** — 환복 후 올라온 친구부터 순차 지급
- **명찰·영수증** — 입장팔찌가 이름표 역할을 합니다(별도 명찰 없음). 회비 영수증은 발급하지 않습니다.
- **1층 담당** — 이선미 집사, 이수진 집사, 박종렬 장로, 조소현 집사
  - 준비물: ☐ 명단표 ☐ 회비납부봉투 ☐ 필기도구 ☐ 티셔츠 ☐ 입장팔찌
- **2층 담당** — 조남선 권사, 서옥래 집사
  - 준비물: ☐ 환영·안내 PPT ☐ 간식 ☐ 별 스티커 ☐ 선물용 볼펜 ☐ 항해사 모자 ☐ 항해사 스카프

### 준비찬양 (16:10 ~ 16:25 / 18:00 ~ 18:15)
- **담당** — 이유진 사모, 지수민 학생, 김동완 학생, 이하음 학생, 찬양팀
- **준비물** — ☐ 준비찬양 PPT ☐ 음원 / (18:00 타임) ☐ 1과 예배 PPT

### 개회예배 (16:25 ~ 17:00, 축도 포함)
- **담당** — 담임 목사님 (참석 가능 확인)
- **장소** — 비전센터 2층
- **단체 사진** — 담임 목사님 설교 후 촬영
- **준비물** — ☐ 개회예배 PPT

### 저녁 식사 (17:00 ~ 18:00)
- **장소** — 식당 / **담당** — 홍선미 집사
- **메뉴** — 불고기, 돈까스(여러 소스) / **간식** — 아이스크림
- **식기** — 식판·수저·물 등 기본 식기는 식당에 구비 (총 70명분 — 상단 인원 참고)
- **준비물** — ☐ 순서 정하기 볼(저·고학년 식사 순서용)

### 1과 설교 (18:15 ~ 18:35)
- **담당** — 김진서 목사
- 설교 중 교사들은 **공과 자리로 이동해 대기**(쉬는 타임)

### 1과 공과 (18:35 ~ 19:45)
- **담당** — 반별 담임교사 / **준비물** — ☐ 각 반 공과 자료
- 공과를 **마치는 순서대로 본당으로 이동**
- ※ **신실반** 담임 부재 → **장충성 집사** 대체 진행
- **공과 장소 조정(1층 2개 반)** — 코스 3(천국문)이 **비전센터 1층 소그룹실**을 미리 꾸며야 하므로, 원래 1층에서 공과하던 **2개 반은 본당 성가대실·자모실로 옮겨** 진행합니다. (사전 세팅이 필요한 곳은 **비전센터 1층뿐**이며, 성가대실 등 다른 코스 장소는 세팅 부담이 적어 공과를 진행한 뒤 바로 전환해도 무방합니다.)
- **아이 인솔 → 본당(전환)** — 공과 진행 전 "공과 후 본당 집결"을 광고하되, 아이들만으로는 놓치기 쉬우므로 **도우미 집사들이 공과가 끝나기 전 각 반으로 가서 아이들을 본당으로 인솔**합니다. 그 사이 **교사들은 약 15~20분간 천로역정을 준비**합니다.

### 천로역정 (마무리 기도회 포함, 19:45 ~ 21:48)

#### 천로역정 (약 120분)
- **⚠️ 세팅 시간 확보** — 교사들이 공과 직후 바로 코스를 세팅해야 해 빠듯합니다. **도우미 집사들이 아이들을 본당으로 인솔하는 동안(공과 종료 전후 15~20분)** 교사들이 코스를 준비하고, 본당에 모인 아이들은 그대로 **천로역정 오프닝**으로 이어집니다. (→ 위 '1과 공과'의 아이 인솔 안내)
- **코스 3 사전 세팅** — 코스 3(천국문)은 미리 꾸며야 하므로 **비전센터 1층 소그룹실은 공과에 쓰지 않습니다**(해당 2개 반은 성가대실·자모실로 이동).
- **장소** — 비전센터 + 야외
- **진행** — [천로역정 순례길 기획안](../천로역정.md)에 맞춰 진행. 교사들이 코스 담당, 교회 집사님들이 조 인솔을 맡음.
- **교구** — 천로역정 기획안 [준비물 총괄](../천로역정.md#5-준비물-총괄)을 따릅니다.
  - ☐ 코스1 배낭·죄의 생수병 ☐ 코스2 나무 십자가·붉은 끈·가위 ☐ 코스3 천국문 장식·생명책 전지·황금 마커·포스트잇 ☐ 코스4 유혹/말씀 카드 ☐ 코스5 안대·발바닥 스티커·안전 장애물 ☐ 코스6 LED 촛불·우드락 십자가·압정·볼펜·종이 ☐ 순례 여권·스티커 ☐ 각 코스 타이머

#### 기도회 = 천로역정 마무리 "천성에 도착하여" (약 10분)
- **별도의 기도회를 따로 두지 않습니다.** 천로역정의 마무리 순서인 **[천성에 도착하여](../천로역정.md)**(본당 집결 → 여정 되짚기 → **통성 기도·은혜 나눔** → 천국 잔치 간식)가 곧 기도회 역할을 겸합니다. 즉 천로역정이 끝나면 바로 그 자리가 기도회입니다.
- **담당** — 마무리(통성 기도·은혜 나눔)는 **교역자(김진서 목사)**가 인도합니다.
- **캠프파이어 대체 검토 중** — 이 마무리(통성 기도·은혜 나눔)를 **본당 앞 캠프파이어**로 옮겨 드릴지 검토 중입니다. 진행 시 본당 대신 본당 앞 캠프파이어에서 여정 되짚기·통성 기도·은혜 나눔을 진행하며(천국 잔치 간식도 함께), 안전(소화기·화기 관리)·소방 점검이 필요합니다. 준비 가능한 봉사자가 있습니다. → [확인·미정](#4-확인미정-사항)

### 야식 (22:00 ~ 22:30)
- **장소** — 식당 (분식) / **담당** — 이정록 집사 (즉석 분식)
- **22:00 부모님 픽업 안내**

### 자유 시간 및 짐 이동 (22:30 ~ 23:00)
- **여자아이** — 2층 초등부실 (1·2층 화장실) / 담당: 이유진 사모, 조소현 집사
- **남자아이** — 3층 유치부실 (3·4층 화장실) / 담당: 김진서 목사, 장충성 집사
- **샤워** — 본당 지하 1층 샤워실 이용 가능 (샤워실 슬리퍼 저가로 준비)
- **야간 대기** — 위 자유시간 담당 4명(여: 이유진 사모·조소현 집사 / 남: 김진서 목사·장충성 집사)이 그대로 밤새 대기합니다.
- 그 외 선생님들은 귀가 → **다음날(토) 오전 7시까지 교회 재집합**

- **침구는 아이들이 개인 지참**(가정통신문 안내). 별도 수면등은 두지 않습니다.

## 3. 인원 배치 점검 (동시간 충돌)

> **⚠️ 핵심 리스크** — 천로역정은 어른 손이 가장 많이 필요한 슬롯인데, 필요 인원이 전체 어른 정원(20명)과 거의 같습니다. 아래 두 표로 미리 점검하세요.

### 천로역정 필요 인원 vs 가용 인원 (19:45 ~ 21:48)

천로역정 기획안([천로역정.md](../천로역정.md))이 요구하는 **동시 인원**:

| 역할 | 인원 | 배정 |
| --- | --- | --- |
| 코스 지기 | **11명** | 코스1 이선미·김옥주 / 코스2 이수진·지수민 / 코스3 조소현·이유진 사모 / 코스4 박미경·김진서 목사 / 코스5 서옥래·김동완 / 코스6 박종렬 |
| 총괄 | **1명** | 장충성 집사 (오프닝 주관 · 마무리 기도회는 교역자 인도) |

## 4. 확인·미정 사항

- [ ] **교사 모임 시간 정리** — 진행표는 '~15:30 교사 모임(기도회)'인데 세부는 '15:00 차량 시작 → 15:30 도착'이라 상충. 기도회 팀 도착 시각·기도회 시각 확정 필요
- [ ] **조 인솔 8명 실명 배정 + 인원 부족 점검** — 천로역정 조 인솔 8명이 미배정입니다. 위 [인원 배치 점검](#3-인원-배치-점검-동시간-충돌) 기준으로 실명 배정하고, 부족 시 학부모 도우미 요청 또는 코스 지기 축소 등을 결정하세요.
- [ ] **신실반 공과 대체자 재배정** — 현재 장충성 집사(총괄)가 겸함. 총괄을 비우기 위해 다른 교사에게 넘길지 결정
- [ ] **PPT 제작** — 준비찬양·개회예배·1과 예배·환영/안내 PPT
- [ ] **항해사 스카프 구매** — 모자는 구매 완료, 스카프 진행 여부 확인
- [ ] **마무리 기도회 vs 캠프파이어** — 천로역정 마무리('천성에 도착하여'=기도회)를 본당에서 드릴지, **본당 앞 캠프파이어**로 옮길지 검토 중. 캠프파이어 진행 시 안전(소화기·화기 관리)·소방 점검 + 준비 담당 봉사자 지정(준비 가능한 분 있음)
- [x] **기도회 담당** — 천로역정 마무리(기도회 겸함)는 **교역자(김진서 목사)** 인도로 확정. 별도 기도회는 두지 않음
- [ ] **통합 예산표 작성** — 천로역정 교구·간식, 티셔츠 수량, 3일차 간식 등 2026 실제 금액을 정산할 예산표 미비 (템플릿 총예산 400만원 기준)
- [ ] **비상 연락망·인근 병원 확인** — 숙박 야간 시간대 비상 연락·응급 동선 점검 (템플릿 [안전 관리](../여름-성경학교.md#6-안전-관리))
- [ ] **천로역정 기획안 재검토** — 여름성경학교 맥락(개회예배 별도, 마무리가 기도회를 겸함)에 맞게 내부 오프닝/마무리 등 추후 재검토
