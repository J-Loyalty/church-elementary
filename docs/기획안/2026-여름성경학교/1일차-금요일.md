## 3. 인원 배치 점검 (같은 시간에 겹침)

> **⚠️ 미리 챙길 점** — 천로역정은 어른 손이 가장 많이 필요한 시간대인데, 필요 인원이 전체 어른 정원(20명)과 거의 같습니다. 아래 두 표로 미리 점검하세요.

### 천로역정 필요 인원 vs 가용 인원 (19:45 ~ 22:28)

천로역정 기획안([천로역정.md](../천로역정.md))이 요구하는 **동시 인원**:

| 역할 | 인원 | 배정 |
| --- | --- | --- |
| 코스 지기 | **11명** | 코스1 이선미·김옥주 / 코스2 이수진·지수민 / 코스3 조소현·이유진 사모 / 코스4 박미경·김진서 목사 / 코스5 서옥래·김동완 / 코스6 박종렬 |
| 총괄 | **1명** | 장충성 집사 (오프닝 주관 · 마무리 기도회는 교역자 인도) |
| 조 인솔 (보조 도우미) | **8명** | 기쁨 김미경 권사 / 절제 장윤봉 장로 / 신실 김만섭 집사 / 사랑 박경식 집사 / 친절 최희영 집사 / 선함 고재욱 장로 / 온유 김정춘 집사 / 인내 김기송 장로 |
| **동시 필요** | **20명** | |

- ✅ **조 인솔 8명 실명 배정 완료** (보조 도우미 — 장로·권사·집사) — 코스 지기·총괄과 겹치지 않아 미배정이던 조 인솔이 모두 채워졌습니다.
- ✅ **사진** — 학생부 도우미 **3명 (기태민·윤주애·손예린)**이 담당(어른 20명과 별도 인력). ※ 학생부 김민후는 **주방 도우미**로, 천로역정 보조에는 포함하지 않음
- ⚠ 단, 조 인솔 8명은 **어른 20명 정원 안에 포함**됩니다. 코스 지기 11명 + 총괄 1명 + 조 인솔 8명 = **20명 전원**이 순례에 투입되므로, **순회 안전·구급은 사진 담당 학생부 도우미(기태민·윤주애·손예린)가 겸임**합니다(어른 20명과 별도 인력). 셋 중 한 명이 구급함을 챙깁니다.

### 개인별 같은 시간에 겹침 (초저녁 ~ 야간)

한 사람이 맡은 역할을 시간대로 늘어놓았습니다. ⚠ = 전환이 빠듯하거나 겹치는 지점.

| 인물 | 초저녁 (접수·식사·찬양) | 공과 18:35~19:40 | 천로역정 19:45~22:28 | 야식·야간 22:40~ |
| --- | --- | --- | --- | --- |
| 장충성 집사 | 총괄 | 신실반 공과 대체(본당 본당석) | **총괄·오프닝**(같은 본당석에서 즉시 연결) | — |
| 김진서 목사 | 1과 설교(18:15) | (쉬는 타임) | 코스4 지기 → ⚠ 마무리 인도 | 남아 야간대기 |
| 이유진 사모 | 준비찬양 인도 | — | 코스3 지기 | 여아 야간대기 |
| 조소현 집사 | 1층 접수 | — | ⚠ 코스3 지기(사전 세팅) | 여아 야간대기 |
| 서옥래 집사 | 2층 접수 | — | 코스5 지기 | — |
| 이선미 집사 | 1층 접수 | 반 담임 | 코스1 지기 | — |
| 이수진·박종렬 | 1층 접수 | 반 담임 | 코스2·코스6 지기 | — |

- **장충성 집사** — ✅ **해결**: 신실반 공과를 **본당 본당석**으로 옮겨, 공과 직후 그 자리에서 곧바로 19:45 오프닝으로 이어갑니다(별동 100m 이동 없음). 대체자를 바꾸지 않고 장소 이설로 해결.
- **김진서 목사** — 코스4 지기 → 순환 종료 후 곧바로 마무리(기도회) 인도. 코스4에서 마무리로 넘어가는 동선을 미리 정리하세요.
- **조소현 집사·이유진 사모(코스3)** — 코스3(천국문)은 사전 세팅이 필요한 **유일한** 곳이라, 이 반은 **공과를 다른 반보다 먼저 끝내고** 코스3부터 세팅해야 합니다. (위 '천로역정' 세팅 안내 참고)

## 4. 확인·미정 사항

- [x] **교사 모임 시간 정리** — 교사는 **15:00까지 집합**해 사전 준비로 확정(버스 15:00 출발 → 15:25 도착 → 15:30 접수). 단, 기도회 팀 도착·기도회 시각은 별도 확정 필요
- [x] **조 인솔 8명 실명 배정** — 보조 도우미 8명 배정 완료 (기쁨 김미경 권사 / 절제 장윤봉 장로 / 신실 김만섭 집사 / 사랑 박경식 집사 / 친절 최희영 집사 / 선함 고재욱 장로 / 온유 김정춘 집사 / 인내 김기송 장로). **안전·구급은 사진 도우미(기태민·윤주애·손예린) 겸임**으로 확정
- [x] **신실반 공과 장소 이설** — 대체자 교체 대신 **첫째날 공과를 본당 본당석으로 이설**해, 총괄(장충성)이 공과 직후 그 자리에서 오프닝을 열도록 해결. 4층(코스5)이 비어 코스5 사전세팅 여유도 확보
- [ ] **환영·안내 PPT 제작** — 담당 **장충성 집사** (준비찬양·개회예배·1~3과 예배 PPT는 제작 완료)
- [x] **항해사 스카프** — 구매하지 않기로 확정(모자만 사용)
- [x] **마무리 기도회 장소** — **본당**에서 짧게 진행으로 확정(캠프파이어 안 함). 담당 교역자(김진서 목사)
- [x] **기도회 담당** — 천로역정 마무리(기도회 겸함)는 **교역자(김진서 목사)** 인도로 확정. 별도 기도회는 두지 않음
- [x] **늦은 취침 시각(23:40)** — 23:40 취침을 수용하되, **자유시간은 필수가 아니라 먼저 자고 싶은 아이는 조기 취침**할 수 있도록 운영(야간 대기 교사 안내). 늦은 취침 부담을 이렇게 완화
- [x] **통합 예산표 작성** — [예산안.html](예산안.html)로 작성 완료 (수입 1,500,000 + 초등부 재정 2,254,000 = 지출 3,754,000, 수지 균형). 실제 정산 시 금액 갱신
- [x] **비상 연락망·인근 병원** — 확보 완료. 순례 시간대 순회 **안전·구급은 사진 도우미(기태민·윤주애·손예린)가 겸임** (템플릿 [안전 관리](../여름-성경학교.md#6-안전-관리))
- [ ] **천로역정 기획안 재검토** — 여름성경학교 맥락(개회예배 별도, 마무리가 기도회를 겸함)에 맞게 내부 오프닝/마무리 등 추후 재검토
