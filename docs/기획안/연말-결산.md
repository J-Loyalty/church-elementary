# [기획안] 연말 결산 (달란트 시상)

한 해 동안 모은 달란트를 결산해 아이들을 시상하는 행사입니다. 연간 계획상 **12월**에 진행합니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 초등부 학생 |
| 시기 | 12월 (연말) |
| 목적 | 한 해 달란트를 결산하고 격려·시상 |
| 예산 | **400,000원** (재원: 교회 재정) |

> 📝 정확한 시점(연말 주일 등)을 확정하세요.

---

## 2. 시상 방식

- **1년간 누적한 종합 달란트**를 기준으로 순위를 매겨 **차등 지급**합니다.
  - 여러 달란트 항목 중 **종합으로만** 결정합니다. (항목별 시상 없음)
- **순위는 전체 아이들에게 공개·발표하지 않습니다.** (경쟁·비교보다 격려에 초점)
- **모든 학생**에게 지급하며, 상위는 차등으로 조금 더 지급합니다.
- **아이별 특징을 새긴 상장**을 제작해 전달하면서 **다이소 상품권**을 함께 줍니다.
- **상품권 금액은 아이들에게 이야기하지 않습니다.** (금액 비공개)
- 상품 금액은 부담되지 않는 선으로 정합니다.

---

## 3. 시상 내역 (예시)

모든 상품은 **다이소 상품권**으로 지급합니다. (금액은 **내부 기준**이며 아이들에게는 공개하지 않고, 개인별 상장과 함께 전달)

| 구분 | 상품 |
| --- | --- |
| 1위 | 20,000원 |
| 2위 | 15,000원 |
| 3위 | 10,000원 |
| 그 외 전체 학생 | 5,000원 |

> 📝 올해 순위별·전체 금액을 확정하세요.

---

## 4. 예산 (교회 재정)

| 항목 | 내용 |
| --- | --- |
| 전체 사은품 | 5,000원 × 전체 학생 수 |
| 1~3위 차등 상품 | 위 기준에서 순위별로 추가 |
| **예산 상한** | **400,000원** |

> 📝 실제 학생 수에 맞춰 40만원 안에서 배분하세요.

---

## 5. 준비 · 역할

- **달란트 최종 집계** — 한 해 누적 종합 달란트를 엑셀로 집계해 순위를 산출합니다. → [달란트 제도](../활동-안내.md#4-달란트-제도)
- **상장 제작** — 아이별 특징을 새긴 상장을 준비합니다.
- **상품권 구매** — 다이소 상품권을 인원·순위에 맞춰 구매합니다. (금액 비공개)
- **시상 진행** — 순위를 공개하지 않고, 개인별 상장과 함께 상품권을 전달합니다.

| 역할 | 담당 |
| --- | --- |
| 총괄 | 부장 (장충성 집사) |
| 달란트 집계 | 담당 교사 (엑셀) |
| 상품권 구매 | 📝 (담당) |
| 회계 | 조남선 권사 |

---

## 6. 준비 체크리스트

- [ ] 한 해 누적 종합 달란트 집계·순위 산출
- [ ] 순위별·전체 금액 확정 (예산 40만원 내, 금액 비공개)
- [ ] 아이별 특징 상장 제작
- [ ] 다이소 상품권 구매 (전체 + 상위 차등)
- [ ] 시상 순서·진행 준비 (순위 미공개, 개인별 상장 전달)
