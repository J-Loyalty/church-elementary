## 2. 공연 구성

> 2026년 공연 구성입니다. (컵타 난타는 작년 반응이 낮아 제외하고, **수어 찬양**을 새로 넣었습니다.) 지도 교사는 확정되는 대로 채우세요.

**약 60명**을 아래 기준으로 배정합니다.

| 공연 | 지도 교사 | 대상·인원 (작년 기준) | 작년 반응 |
| --- | --- | --- | --- |
| 우산 댄스 | 📝 | 유년부 여아 10~15명 | 괜찮았음 (유지) |
| 태권도 댄스 | 📝 | 태권도 가능한 유·초등부 10~15명 | 괜찮았음 (유지) |
| 연극 | 📝 | 초등부 10명 내외 | 괜찮았음 (유지) |
| 댄스 워십 | 📝 | 찬양팀 10명 내외 | 괜찮았음 (유지) |
| 수어 찬양 | 📝 | 10명 내외 | 신규 (올해 처음) |
| 전체 찬양 | (전체) | 전체 | — |

작년 반응은 현장에서 함께 본 기준입니다. **컵타·난타는 반응이 낮아 올해 제외**했고, 나머지는 무난해 이어갑니다.

### 배정 원칙 (작년 교훈 반영)

작년에는 특정 팀(컵타·난타)에 **배정되지 않은 아이들을 전부 몰아넣었더니**, 그 팀이 하기 싫어하는 아이들 위주가 되어 연습도 진행도 매끄럽지 않았습니다. 올해는 이렇게 합니다.

- 특별한 조건(유년부 여아·태권도 가능·찬양팀 등)이 없는 아이들, 특히 **적극적이지 않은 아이들을 한 팀에 몰지 않고 여러 공연에 고르게 나눠** 배치합니다.
- 각 팀 지도 교사가 소극적인 아이들도 **한두 명씩 맡아 함께** 이끌도록 하여, 한 팀이 통째로 힘들어지지 않게 합니다.
- 아이의 희망을 먼저 반영하되, 쏠림이 없도록 교사들이 균형을 맞춥니다.

- **수어 찬양**은 성탄 찬양을 손짓(수어)으로 표현하는 무대입니다. 가사에 성탄의 복음이 분명히 담기도록 곡을 고릅니다.
- 인원은 작년 기준이며, 📝 올해 실제 인원·희망에 맞춰 조정하세요.

- 팀 배정은 **학생 희망 신청 → 남은 인원 교사 배분**으로 균형을 맞춥니다. (→ [성탄 연습](../성탄-연습.md#3-팀-배정))
- 각 무대의 곡·가사·연극 내용은 **성탄의 복음 메시지**가 담기도록 고릅니다.

### 여유분 공연 (후보 · 인원 미배정)

위 6개 외에, 필요할 때 더하거나 바꿔 쓸 수 있는 후보 무대입니다. 인원은 따로 배정하지 않고, 하기로 정해지면 그때 편성합니다. 모두 성탄의 복음을 담는 것을 우선합니다.

- **핸드벨(벨) 연주** — 성탄 캐럴을 벨로 잔잔하게 연주하는 경건한 무대
- **성탄 이야기 낭독극** — 예수님의 탄생 이야기(누가·마태복음)를 낭독과 장면으로 전하는 말씀 중심 무대
- **악기 합주** — 아이들이 **집에 있는 쉬운 악기**(탬버린·리코더·멜로디언·에그셰이커 등)를 가져와 성탄 캐럴을 함께 연주하는 무대. 따로 사지 않아도 되고, 악기를 잘 못 다뤄도 누구나 참여하기 좋습니다.
