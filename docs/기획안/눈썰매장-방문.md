# [기획안] 겨울 성경학교 대체 — 눈썰매장 방문

겨울 성경학교를 대체하는 2월 야외 행사 기획안입니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 행사명 | 겨울 성경학교 대체 — 눈썰매장 방문 |
| 목적 | 겨울철 야외 활동을 통한 부서 친교 및 공동체 형성 — 하나님이 주신 계절과 자연 안에서 함께 즐거워하며 믿음의 공동체로 세워짐 |
| 일시 | 📝 2월 첫째 또는 둘째 주 **토요일** 09:30 ~ 14:00경 |
| 장소 | 김포조각공원 사계절 눈썰매장 |
| 대상 | 학생 및 교사 (+ 동반 보호자) |
| 예상 인원 | 학생 약 50명 + 교사 10명 내외 = 약 60명 (동반 보호자 별도) |
| 이동 수단 | 교회 차량 3대(25인승 버스·12인승·10인승 스타렉스, 총 47석) + 부족 시 교사 자차, 일부 보호자 자차 |
| 식사·간식 | 학생·교사 제공 / 동반 보호자(중학생 이상) 1인 10,000원 |

**참가 안내**
- 학생과 교사는 부서에서 지원합니다.
- **동반 보호자(중학생 이상)** 는 1인 **10,000원**입니다.
- 초등부 학생의 형제·자매 중 **미취학 아동이 동반할 경우, 보호자가 반드시 함께 참석**해 주세요.

> **차량 계획:** 예상 인원(약 60명)에 동반 보호자를 더하면 교회 차량 3대(총 47석)를 초과합니다. 부족한 인원은 **교사 자차**로 이동하고, **일부 보호자는 자차 이용 여부를 사전 조사**해 좌석을 확보합니다.

## 5. 준비물

**부서 준비물**
- 구급함(상비약), 여분 장갑·양말, 큰 비닐봉투(젖은 옷)
- 조별 명단·비상 연락망, 이름표
- 간식·식수, 상품(레크레이션 시)
- 점심용 한솥 도시락 예약(교회 도착 후 배식)
- 카메라 / 휴대폰 충전기

**개인 준비물 (사전 안내)**
- 방수 방한복, 방한장갑, 모자, 목도리
- 여벌 옷·양말, 방수 신발(부츠)
- 개인 물통, 필요 시 개인 약

## 6. 안전 관리

- **차량 운행** — 교회 차량 3대에 인원을 나누어 배정하고, 부족분은 교사 자차·일부 보호자 자차로 이동합니다. 차량별 운전자·동승 교사·탑승 명단을 정하고, 겨울철 도로 상황을 감안해 안전 운행합니다.
- **조별 인솔** — 반별로 조를 나누고 담당 교사가 인원을 수시로 점검합니다.
- **안전 교육** — 도착 직후 눈썰매장 이용 수칙과 집결 장소·시간을 공지합니다.
- **비상 연락망** — 교사·학부모 연락처를 사전에 정리합니다.
- **응급 대응** — 구급함을 준비하고, 인근 병원 위치를 미리 확인합니다.

> 📝 눈썰매장 자체 안전 규정과 인솔 인원 기준을 확인해 반영하세요.
