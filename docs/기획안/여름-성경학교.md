# [기획안] 여름 성경학교

총회 여름성경학교 교재로 진행하는 **2박 3일(금·토·주일)** 행사입니다. 연간 계획상 **7월**에 진행합니다.
프로그램은 매년 다르지만 기본 구조는 비슷합니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

## 6. 안전 관리

**숙박**
- 취침 전 인원 점검, 야간 대기 교사를 정합니다.
- 남녀 숙소·화장실 동선을 분리하고 안전을 확인합니다.

**물놀이 (가장 중요)**
- 입수 전 안전 교육과 준비운동을 진행합니다.
- 조별 인솔 교사가 **수시로 인원을 점검**합니다.
- 안전요원·구명 인력 배치와 물놀이장 안전 규정을 확인합니다.
- 물놀이 구역·시간을 정하고, 저학년은 교사 밀착 인솔합니다.

**이동 · 공통**
- 교회 차량으로 이동하며 겨울철에 준해 안전 운행합니다.
- 구급함·비상 연락망을 준비하고, 인근 병원 위치를 확인합니다.

> 📝 숙박·물놀이 인솔 인원 기준을 확정하세요.
