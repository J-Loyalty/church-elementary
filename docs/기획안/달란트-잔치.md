# [기획안] 상/하반기 달란트 잔치

한 학기 동안 모은 달란트를 사용하는 부서 잔치입니다. 연간 계획상 **4월/10월**에 진행합니다.
달란트 적립 방식은 [활동 안내 – 달란트 제도](../활동-안내.md#4-달란트-제도)를 참고하세요.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 한 학기 신앙생활·활동의 열매를 나누고 격려 |
| 시기 | 4월 (상반기) / 10월 (하반기) |
| 대상 | 유년부·초등부 학생 및 교사 |
| 총예산 | **1,600,000원** (재원: 교회 재정) |

---

## 2. 진행 방식 (달란트 환산 · 사전 구매)

일반적인 달란트 잔치와 큰 틀은 같지만, **달란트를 금액으로 환산해 아이들이 원하는 물건을 미리 사는** 방식입니다.

**① 달란트 집계**
- 달란트는 매주 출석체크와 함께 적립하며, **엑셀로 정리해 자동 계산**합니다.
- 모든 아이들의 달란트를 합산해 총 달란트 수를 구합니다.

**② 1달란트당 금액 산정**
- **아이들 물품 예산(1,000,000원) ÷ 전체 달란트 합계 = 1달란트당 금액**

**③ 개인별 금액 환산**
- 총 달란트에서 **헌금(십일조 의무 + 감사·선교·구제 자율)** 과 **식대(기본 20달란트)** 를 뺀 나머지로 사용 가능 금액이 정해집니다.
- 남은 달란트 × 1달란트당 금액 = 개인이 사용할 수 있는 금액

**④ 희망 물품 사전 구매**
- 아이들이 자기 금액 안에서 원하는 물건을 미리 신청하고, 부서가 구매합니다.

**⑤ 당일 달란트 사용**
- 잔치 당일에는 **식사·물품을 달란트로 구매**하고, **다양한 프로그램(성경퀴즈·제기차기 등)으로 추가 달란트**를 얻을 수 있습니다.

**⑥ 미사용 금액 처리**
- 아이가 다 쓰지 않은 금액은 **초등부 예산**으로 전환되어, 부서 물품 구매(30만원 + α)에 사용됩니다.

**계산 예시**

> - 전체 달란트 합계가 **2,000달란트**라면
> - 1달란트당 금액 = 1,000,000 ÷ 2,000 = **500원**
> - 40달란트를 모은 학생 → 십일조 4 + 식대 20 = **24달란트 차감**, 남은 **16달란트**
> - 16 × 500 = **8,000원** 사용 가능
> - 미사용분은 초등부 예산으로 전환

## 3. 예산

| 항목 | 금액 | 비고 |
| --- | --- | --- |
| 식대 | 300,000원 | 잔치 식사 |
| 부서(초등부) 물품 구매 | 300,000원 + α | 30만원 + 아이들 미사용 잔액(α) |
| 아이들 물품 구매 | 1,000,000원 | **1달란트 환산 기준 금액** |
| **합계** | **1,600,000원** | 재원: 교회 재정 |

- 아이들 물품 예산 중 **미사용분(α)은 초등부 예산으로 전환**되어 부서 물품 구매에 사용됩니다.

## 4. 진행 흐름 (당일)

| 순서 | 내용 | 담당 |
| --- | --- | --- |
| 여는 순서 | 인사·기도, 잔치 소개 | 부장 |
| 말씀 | 달란트 관련 설교 | 교역자 |
| 달란트 헌금 | 십일조(의무)·감사·선교·구제 헌금을 **달란트로** 드림 | 교역자 |
| 물품 전달 | 사전 구매한 물품을 아이들에게 전달 | 담당 교사 |
| 부스 운영 | 식사·물품을 달란트로 구매 (판매: 청년부 또는 초등부 교사) | 봉사자·교사 |
| 달란트 게임 | 성경퀴즈·제기차기 등으로 추가 달란트 획득 | 📝 (담당) |
| 마침 | 마침 기도·정리 | 부장 |

**달란트 헌금 안내**
- 여는 순서에서 달란트 관련 설교 후, 아이들이 **자기 달란트로** 헌금을 드립니다.
- **십일조** — 의무 (모은 달란트의 십일조)
- **감사 · 선교 · 구제** — 자율 (원하는 아이가 자유롭게)
- 헌금으로 드린 달란트를 **제외한 나머지 달란트로 사용 가능 금액이 결정**됩니다.

- **식사 메뉴(예)** — 떡볶이, 회오리 감자, 김밥, 라면, 과자 등 (기본 식대 20달란트로 구매)

> 📝 실제 프로그램 순서와 시간을 확정하세요.

## 5. 사전 준비 (환산·구매 일정)

| 시기 | 할 일 |
| --- | --- |
| 상시 | 매주 출석체크로 달란트 적립·엑셀 정리 |
| 3~4주 전 | 달란트 최종 집계, 전체 합계 산출 |
| 3주 전 | 1달란트당 금액 산정, 아이별 금액 환산·안내 |
| 2주 전 | **희망 물품 조사·구매**(배송 기간 고려), 음식 봉사자·판매(청년부) 요청 |
| 1주 전 | 미사용 잔액으로 부서 물품 구매, 식사·게임·상품 준비, 물품 포장·분류 |
| 전날 | 물품·명단 최종 점검 |

## 6. 역할 분담

| 역할 | 담당 | 내용 |
| --- | --- | --- |
| 총괄 | 부장 (장충성 집사) | 전체 진행 |
| 달란트 집계·환산 | 담당 교사, 김동완 학생 | 매주 출석체크 적립, 엑셀 자동 계산·환산 |
| 물품 구매 | 교역자 · 부장 · 시간 되는 교사 | 희망 물품·부서 물품 구매 |
| 회계 | 조남선 권사 | 예산 집행·정산 |
| 음식 준비 | 별도 봉사자 | 떡볶이·회오리 감자·김밥·라면·과자 등 |
| 판매(부스) | 청년부 요청 또는 초등부 교사 | 식사·물품 판매 부스 운영 |
| 달란트 게임 | 📝 (담당) | 성경퀴즈·제기차기 등 |

## 7. 준비 체크리스트

- [ ] 달란트 최종 집계·전체 합계 산출
- [ ] 1달란트당 금액 산정
- [ ] 아이별 환산 금액 안내
- [ ] 희망 물품 조사·구매 (2주 전, 배송 기간 고려)
- [ ] 미사용 잔액 집계 → 초등부 예산으로 부서 물품 구매
- [ ] 음식 봉사자 요청 (떡볶이·회오리 감자·김밥·라면·과자 등)
- [ ] 판매 부스 운영 요청 (청년부 / 초등부 교사)
- [ ] 달란트 게임 준비 (성경퀴즈·제기차기)
- [ ] 달란트 관련 설교·헌금 순서 준비 (십일조/감사/선교/구제)
- [ ] 물품 포장·명단 분류
