# [기획안] 상/하반기 달란트 잔치

한 학기 동안 모은 달란트를 사용하는 부서 잔치입니다. 연간 계획상 보통 **4월/10월**에 진행합니다. (하반기 시기는 해에 따라 조정될 수 있습니다 — 예: 2026년은 9월 셋째 주.)
달란트 적립 방식은 [활동 안내 – 달란트 제도](../활동-안내.md#4-달란트-제도)를 참고하세요.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 한 학기 신앙생활·활동의 열매를 나누고 격려 |
| 시기 | 4월 (상반기) / 10월 (하반기) |
| 대상 | 유년부·초등부 학생 및 교사 |
| 총예산 | 상반기 **1,600,000원** · 하반기 **1,900,000원** (재원: 교회 재정) |

---

## 2. 진행 방식 (달란트 환산 · 사전 구매)

일반적인 달란트 잔치와 큰 틀은 같지만, **달란트를 금액으로 환산해 아이들이 원하는 물건을 미리 사는** 방식입니다.

**① 달란트 집계**
- 달란트는 매주 출석체크와 함께 적립하며, **엑셀로 정리해 자동 계산**합니다.
- 모든 아이들의 달란트를 합산해 총 달란트 수를 구합니다.

**② 1달란트당 금액 산정**
- **달란트 물품(희망 물품) 예산 ÷ 전체 달란트 합계 = 1달란트당 금액** (하반기 1,100,000원 기준 · 📝 상반기 조정)
- 간식·예비 물품·분식은 이 환산과 **별개**이며, 당일 부스에서 달란트로 삽니다. (아래 ⑤)

**③ 개인별 금액 환산**
- 총 달란트에서 **헌금(십일조 의무 + 감사·선교·구제 자율)** 과 **식대(기본 20달란트)** 를 뺀 나머지로 사용 가능 금액이 정해집니다.
- 남은 달란트 × 1달란트당 금액 = 개인이 사용할 수 있는 금액

**④ 희망 물품 사전 구매**
- 아이들이 자기 금액 안에서 원하는 물건을 미리 신청하면, **담임 교사가 반별로 개별 구매한 뒤 교회에 청구(영수증)**합니다. 구매한 물품은 잔치 당일 아이에게 전달합니다.

**⑤ 당일 달란트 사용**
- 당일에는 **성경퀴즈·제기차기 등 게임으로 추가 달란트**를 얻고, 그 달란트로 **간식·예비 물품**을 삽니다.
- 희망 물품은 모아 온 달란트로 미리 신청해 당일 받고, 분식은 **기본 식대 20달란트**로 사 먹습니다.

**⑥ 남은 물품 처리**
- 행사 후 남은 물품(예비 물품 포함)은 **부서 공용으로 보관**해 이후 활동에 활용합니다.

**계산 예시**

> - 희망 물품 예산이 **1,100,000원**(하반기), 전체 달란트 합계가 **2,000달란트**라면
> - 1달란트당 금액 = 1,100,000 ÷ 2,000 = **550원**
> - 40달란트를 모은 학생 → 십일조 4 + 식대 20 = **24달란트 차감**, 남은 **16달란트**
> - 16 × 550 = **8,800원** 어치 희망 물품 신청 가능
> - 간식·예비 물품은 당일 게임으로 번 추가 달란트로 구매

## 3. 예산

예산은 **달란트 물품 · 간식 · 식대 · 예비** 네 갈래입니다. (아래는 하반기 기준 · 📝 상반기는 총액 1,600,000원에 맞춰 조정)

| 예산 | 내용 | 무엇으로 사나 | 하반기 |
| --- | --- | --- | --- |
| 달란트 물품 | 아이들 **희망 물품** (사전 신청) | 모아 온 달란트(환산) | 1,100,000원 |
| 간식 | 음료·과자·컵라면 | 당일 게임으로 번 **추가 달란트** | 200,000원 |
| 식대 | 분식(떡볶이·회오리 감자·떡꼬치) | **기본 식대 20달란트** (+ 추가 달란트) | 300,000원 |
| 예비 | 여유분 물품 | 당일 게임으로 번 **추가 달란트** | 300,000원 |
| **합계** | | | **1,900,000원** |

- **모아 온 달란트**는 (헌금·기본 식대를 뺀 뒤) 환산되어 **희망 물품**(달란트 물품 예산)을 사는 데 쓰입니다.
- 그래서 **간식·예비 물품은 당일 게임(성경퀴즈·제기차기 등)으로 추가 달란트를 벌어야** 살 수 있습니다. — 게임 참여를 격려하는 구조입니다.
- **분식**은 모든 아이에게 주는 **기본 식대 20달란트**로 최소한 사 먹을 수 있고, 더 원하면 추가 달란트로 삽니다.
- 총액 1,900,000원은 [2026 예산](../예산/2026.md)과 같습니다. 📝 해에 따라 갱신하세요.

## 4. 진행 흐름 (당일)

| 순서 | 내용 | 담당 |
| --- | --- | --- |
| 여는 순서 | 인사·기도, 잔치 소개 | 부장 |
| 말씀 | 달란트 관련 설교 | 교역자 |
| 달란트 헌금 | 십일조(의무)·감사·선교·구제 헌금을 **달란트로** 드림 | 교역자 |
| 물품 전달 | 사전 구매한 물품을 아이들에게 전달 | 담당 교사 |
| 부스 운영 | 분식·간식·물품을 달란트로 구매 (판매: 청년부 또는 초등부 교사) | 봉사자·교사 |
| 달란트 게임 | 성경퀴즈·제기차기 등으로 추가 달란트 획득 | 📝 (담당) |
| 마침 | 마침 기도·정리 | 부장 |

**달란트 헌금 안내**
- 여는 순서에서 달란트 관련 설교 후, 아이들이 **자기 달란트로** 헌금을 드립니다.
- **십일조** — 의무 (모은 달란트의 십일조)
- **감사 · 선교 · 구제** — 자율 (원하는 아이가 자유롭게)
- 헌금으로 드린 달란트를 **제외한 나머지 달란트로 사용 가능 금액이 결정**됩니다.

**부스 판매 (달란트로 구매)**
- **분식** (식대 예산) — 떡볶이·회오리 감자·떡꼬치. 모든 아이에게 **기본 식대 20달란트**를 지급해 최소한 사 먹게 합니다.
- **간식** (간식 예산) — 음료·과자·컵라면. **게임으로 번 추가 달란트**로 삽니다.
- **예비 물품** (예비 예산) — 여유분 물품. 역시 **추가 달란트**로 삽니다.
- 사전 신청한 **희망 물품**은 당일 전달합니다. (모아 온 달란트로 미리 구매)
- 📝 품목별 **판매 가격(달란트)** 을 미리 정해, 준비한 수량 안에서 팔리도록 합니다.

**달란트 게임 (추가 획득)**
- 간식·예비 물품은 당일 게임으로 번 **추가 달란트**로 사므로, 그 예산만큼을 게임으로 나눠 주도록 준비합니다. (예: 간식·예비 예산 ÷ 물품 단가 = 나눠 줄 달란트 총량)
- **운(복권)이 아니라 준비와 참여에 상을 줍니다.** 게임마다 **달란트와 시도 횟수를 미리 정해 두고, 성공하면 정해진 달란트를 그대로** 받게 합니다. 맡은 것에 성실히 준비한 만큼 상을 받는 것이라 달란트 비유(마 25장 "착하고 충성된 종")의 뜻과 잘 맞습니다.
- **성경 퀴즈** — 문제를 **하루 전 미리 나눠 주어**(가정에서 공부) 준비해 오게 합니다. 저학년·고학년 문제를 나눠 누구나 성공하도록 합니다.
- **성경 암송** — 아이들이 **살아가며 붙들 말씀 2~3구절**을 정해 미리 알려 주고 외워 오게 합니다. 저학년은 부분 암송도 인정해 격려합니다.
- **제기차기 등 놀이** — 목표를 낮게 잡아 대부분 성공하게 하여, 암송이 어려운 아이도 함께 달란트를 얻게 합니다.
- 📝 게임별 **지급 달란트·시도 횟수**와 **암송 구절**을 확정하세요. (모든 아이가 최대치를 받지는 않으므로 실제 지급은 예산 안에 들고, 남은 물품은 부서에서 보관합니다.)

> 📝 실제 프로그램 순서와 시간을 확정하세요.

## 5. 사전 준비 (환산·구매 일정)

| 시기 | 할 일 |
| --- | --- |
| 상시 | 매주 출석체크로 달란트 적립·엑셀 정리 |
| 3~4주 전 | 달란트 최종 집계, 전체 합계 산출 |
| 3주 전 | 1달란트당 금액 산정, 아이별 금액 환산·안내 |
| 2주 전 | **희망 물품 조사** → **담임 교사 반별 개별 구매**(배송 기간 고려·영수증 청구), 분식 조리 봉사자·판매(청년부) 요청, 부스 **판매 가격(달란트)** 정하기 |
| 1주 전 | **예비 물품·간식(음료·과자·컵라면)·분식 재료 구매**, 게임·상품 준비, 희망 물품 취합·포장·명단 분류 |
| 전날 | 물품·명단 최종 점검 |

## 6. 역할 분담

| 역할 | 담당 | 내용 |
| --- | --- | --- |
| 총괄 | 부장 (장충성 집사) | 전체 진행 |
| 달란트 집계·환산 | 담당 교사, 김동완 학생 | 매주 출석체크 적립, 엑셀 자동 계산·환산 |
| 희망 물품 구매 | 담임 교사 (반별) | 반 아이들 희망 물품 **개별 구매 후 교회 청구**(영수증) |
| 예비 물품 구매 | 교역자 · 부장 | 게임용 달란트 물품(예비) 구매 |
| 회계 | 조남선 권사 | 예산 집행·정산 (담임 물품 구매 청구 정산) |
| 분식 조리 | 별도 봉사자 | 떡볶이·회오리 감자·떡꼬치 등 (식대 예산) |
| 간식 준비 | 📝 (담당) | 음료·과자·컵라면 구매·비치 (간식 예산) |
| 판매(부스) | 청년부 요청 또는 초등부 교사 | 식사·간식·물품 판매 부스 운영 (달란트 수납) |
| 달란트 게임 | 📝 (담당) | 성경퀴즈·제기차기 등 |

## 7. 준비 체크리스트

- [ ] 달란트 최종 집계·전체 합계 산출
- [ ] 1달란트당 금액 산정
- [ ] 아이별 환산 금액 안내
- [ ] 희망 물품 조사 → **담임 교사 개별 구매 후 교회 청구**(영수증 · 2주 전, 배송 기간 고려)
- [ ] 간식·예비 물품 구매 (간식·예비 예산 — 게임 달란트로 판매)
- [ ] 분식 조리 봉사자 요청 (떡볶이·회오리 감자·떡꼬치 — 식대 예산)
- [ ] 부스 판매 가격(달란트) 책정 (준비 수량 안에서)
- [ ] 판매 부스 운영 요청 (청년부 / 초등부 교사)
- [ ] 달란트 게임 준비 — 게임별 달란트·시도 횟수 확정 / 성경 퀴즈 문제 **하루 전 배부** / 암송 구절 2~3개 확정·안내
- [ ] 달란트 관련 설교·헌금 순서 준비 (십일조/감사/선교/구제)
- [ ] 물품 포장·명단 분류
