# [기획안] 황동노회 사생대회 참여

황동노회가 주관하는 연합 행사로, **유치부·초등부·학생부가 함께** 참여합니다. 연간 계획상 **5월**에 진행합니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 성격 | 황동노회 연합 사생대회 (유치부·초등부·학생부 공동) |
| 시기 | 5월 |
| 장소 | 서울랜드 (거의 매년 동일) |
| 대상 | 초등부 학생·교사 (+ 자차로 참여하는 가정) |
| 교육위원회 지원 | **45인승 버스 대절**, **간식 제공** |
| 초등부 예산 | 약 **700,000원** (재원: 📝 교회 재정) |

---

## 2. 회비 및 비용

| 구분 | 내용 |
| --- | --- |
| 노회 청구액 | 아이 **25,000원** · 어른 **20,000원** |
| 회비(납부) | 아이·어른 모두 **1인 20,000원** |
| 부서 지원 | 아이 **차액 5,000원 × 아이 수** · **교사 전액(20,000원)** · **식사비** |
| 교육위원회 제공 | 45인승 버스 대절, 간식 |

- 아이는 노회 청구액(25,000원)보다 적은 **20,000원만 납부**하고, **차액 5,000원을 부서가 아이 수만큼 지원**합니다.
- 교사는 회비를 내지 않고 **부서가 전액 부담**합니다.
- 초등부 부담(예산)은 아이 차액·교사·식사비를 합해 **약 70만원** 수준입니다.

---

## 3. 일정 (당일)

| 시간 | 내용 |
| --- | --- |
| 07:30 | 교회에서 서울랜드로 출발 (교육위원회 45인승 버스) |
| 09:30 | 서울랜드 도착·집결 (**동문**), 인원 점검 |
| 09:30 ~ 11:00 | 예배 및 그림/글짓기 대회 (사생대회) |
| 11:00 ~ | 점심 식사 |
| 식사 후 ~ 16:00 | 자유롭게 놀이기구 이용 |
| 16:00 | 버스 출발 · 귀가 |

- 작품·단체 **사진은 미리 촬영**해 두고, 식사 후에는 자유롭게 이용합니다.
- **자차로 참여하는 가정** — 오전 9:30까지 **서울랜드 동문**에서 만나고, **귀가는 자유롭게** 합니다.

---

## 4. 이동

- **단체** — 교육위원회가 대절한 **45인승 버스** 이용
- **자차 가정** — 서울랜드 동문에서 9:30 합류, 귀가 자유
- 버스 탑승 인원·자차 인원을 사전에 조사해 배정합니다.

---

## 5. 준비물

**부서 준비물**
- 조별 명단·비상 연락망, 이름표
- 구급함(상비약), 식수
- 미아 방지용 표식(부서 조끼·팔찌 등), 상품(필요 시)

**개인 준비물 (사전 안내)**
- 편한 복장·운동화, 모자, 자외선 차단제
- 개인 물통, 필요 시 개인 약, 우비(우천 시)

---

## 6. 안전 관리

- **조별 인솔** — 반별로 조를 나누고 담당 교사가 인원을 수시로 점검합니다.
- **미아 방지** — 집결 장소·시간을 반복 공지하고, 저학년은 교사 밀착 인솔합니다.
- **비상 연락망** — 교사·학부모 연락처와 노회 담당자 연락처를 준비합니다.
- **응급 대응** — 구급함을 준비하고, 서울랜드 내 안내소·의무실 위치를 확인합니다.

> 📝 놀이기구 이용 시 안전 수칙과 인솔 인원 기준을 확인하세요.
