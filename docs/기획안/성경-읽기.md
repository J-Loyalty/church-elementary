# [기획안] 성경 읽기

아이들이 스스로 말씀을 읽는 습관을 기르는 활동입니다. **연 3회, 회당 8주 과정**으로 진행합니다.
달란트 적립 방식은 [활동 안내 – 달란트 제도](../활동-안내.md#4-달란트-제도)를 참고하세요.

> 이 문서는 매년 반복되는 활동의 **재사용 템플릿**입니다. 해마다 달라지는 값(시기·읽기 범위 등)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 스스로 말씀을 읽는 습관 형성 |
| 대상 | 초등부 학생 |
| 횟수 | **연 3회** |
| 기간 | 1회당 **8주 과정** |
| 보상 | 완독 시 **20달란트** |

> 📝 연 3회의 시작 시기(예: 학기 초 등)를 확정하세요.

---

## 2. 진행 방식

- 정해진 **읽기 범위**를 **8주에 걸쳐** 스스로 읽습니다.
- 읽기표(체크표)로 진도를 확인하고, **8주 과정을 완독하면 20달란트**를 지급합니다.
- 완독은 읽기표·확인 방법으로 점검합니다.

> 📝 회차별 읽기 범위(예: 신약 복음서 등)와 완독 확인 방법을 정하세요.

---

## 3. 일정 (연 3회)

| 회차 | 시기 | 읽기 범위 |
| --- | --- | --- |
| 1회차 | 📝 | 📝 |
| 2회차 | 📝 | 📝 |
| 3회차 | 📝 | 📝 |

- 각 회차는 **8주**로 진행합니다.

---

## 4. 달란트

- **완독 시 20달란트** — 달란트 항목 중 가장 큰 배점으로, 말씀 읽기에 무게를 둡니다. → [달란트 제도](../활동-안내.md#4-달란트-제도)

---

## 5. 준비 · 역할

- **읽기 범위·일정 선정** — 회차별 범위와 8주 일정을 정합니다.
- **읽기표 제작** — 학생용 진도 체크표를 만듭니다.
- **진도 확인·달란트 지급** — 완독을 확인하고 달란트를 지급합니다.

| 역할 | 담당 |
| --- | --- |
| 총괄 | 부장 (장충성 집사) |
| 진도 확인·달란트 지급 | 반별 담임교사 |
| 달란트 집계 | 담당 교사 (엑셀) |

---

## 6. 준비 체크리스트

- [ ] 회차별 읽기 범위·8주 일정 확정
- [ ] 읽기표(체크표) 제작·배부
- [ ] 완독 확인 방법 정하기
- [ ] 완독자 달란트(20) 지급·집계
