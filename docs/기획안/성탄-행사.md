# [기획안] 성탄 행사 (공연 당일)

성탄절에 진행하는 **교회 전체 행사**입니다. 초등부는 [성탄 연습](성탄-연습.md)에서 준비한 공연을 발표합니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 일시 | 성탄절(주일) — **오전 주일 예배 후, 오후 3시부터** |
| 성격 | 교회 전체 행사 (유치부·초등부·학생부·청년부·장년) |
| 순서 결정 | 교회 내 교역자들이 결정 |
| 초등부 역할 | 성탄 연습에서 준비한 공연 발표 |

---

## 2. 진행

| 시간 | 내용 |
| --- | --- |
| 오전 | 주일 예배 (평소와 동일) |
| 오후 3:00 ~ | 부서별 준비 프로그램 발표 (유치부·초등부·학생부·청년부·장년) |

- 공연 순서는 교역자들이 정하므로, 초등부는 배정된 순서에 맞춰 대기·발표합니다.

---

## 3. 초등부 준비 사항

- **최종 리허설** — 행사 전 공연별 리허설로 동선·음향을 점검합니다.
- **소품·의상·음향** — 공연별 준비물을 당일 챙깁니다. (→ [성탄 연습](성탄-연습.md))
- **대기·이동** — 공연 순서에 맞춘 대기 장소와 이동 동선을 정합니다.
- **학생 인솔** — 담당 교사가 공연 전후 학생을 인솔·점검합니다.
- **성탄 선물** — 학생 선물을 준비해 전달합니다. (예산은 [성탄 연습](성탄-연습.md#5-예산-교회-재정) 참고)

---

## 4. 역할

| 역할 | 담당 |
| --- | --- |
| 총괄 | 부장 (장충성 집사) |
| 공연별 지도 | 담당 교사 (팀별) |
| 음향·영상 | 찬양팀(방송) |
| 선물 준비·전달 | 📝 (담당) |
