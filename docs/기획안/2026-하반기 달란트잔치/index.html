물품 구매 가이드 — 달란트 물품 예산 1,100,000원으로 아이들 희망 물품 구매 시 개당 단가 177원 이하 위주로 구성 (달란트 단가 유지). 간식·예비 물품은 당일 게임으로 번 추가 달란트로 삽니다.
게임으로 나눠 줄 달란트 — 간식·예비 예산(합 500,000원)을 모두 소진하려면, 게임으로 아이들에게 약 2,826달란트를 나눠 주어야 합니다 (물품 단가 177원 기준). 게임 문항·기회 수를 여기에 맞춰 준비하세요.
희망 물품 구매 방식 — 희망 물품은 담임 선생님이 각 반 신청을 전달받아 개별 구매한 뒤, 영수증으로 교회에 청구합니다. 구매한 물품은 당일 아이에게 전달합니다.
📝 물품 사전 구매는 아직 시작 전입니다. 진행되는 대로 사전 주문 완료 금액·현장 구매 잔액을 이 표에 갱신하세요.
