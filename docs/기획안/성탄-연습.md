# [기획안] 성탄 연습

성탄절 공연을 준비하는 연습 기간에 대한 기획안입니다. 연간 계획상 **11월**에 시작합니다.
진행 방식은 매년 바뀌며, 아래는 **기본 구성(예시)**입니다.

> 이 문서는 매년 반복되는 행사의 **재사용 템플릿**입니다. 해마다 달라지는 값(날짜·인원·금액·구성)은 `📝`를 채우거나 갱신해 사용하세요.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 목적 | 성탄절 공연 준비 |
| 기간 | **11월 셋째 주 ~ 성탄절** |
| 대상 | 유년부·초등부 학생 및 교사 |
| 연습 시간 | **토요일**(주 연습) + **주일 공과 시간 대체** |

> 진행 방식은 매년 바뀝니다. 올해 방식이 정해지면 아래 내용을 갱신하세요.

---

## 2. 공연 구성 (예시)

기본적으로 여러 공연으로 나누어 진행하며, 구성 예시는 다음과 같습니다.

> 공연은 보여 주기가 목적이 아니라, **예수님이 이 땅에 오신 성탄의 기쁨과 복음**을 함께 전하고 고백하는 시간입니다. 무대마다 그 의미가 담기도록 곡·가사·연극 내용을 고르고, 아이들에게도 "우리가 왜 이 무대를 준비하는지"를 미리 나눠 주세요.

1. 우산 댄스
2. 태권도 댄스
3. 컵타 난타
4. 연극
5. 댄스 워십
6. 전체 찬양

> 📝 올해 공연 종류·개수를 확정하세요.

---

## 3. 팀 배정

- **1순위** — 학생이 하고 싶은 공연을 먼저 신청합니다.
- **2순위** — 남은 인원은 **교사들이 인원을 배분**해 팀별 균형을 맞춥니다.
- 소극적이거나 특별한 조건이 없는 아이들을 **한 팀에 몰지 말고 여러 공연에 고르게 분산**합니다. (배정 안 된 아이들을 한 팀에 몰았더니 그 팀 연습·진행이 어려웠던 지난 성탄 교훈)

| 공연 | 지도 교사 | 인원 |
| --- | --- | --- |
| 우산 댄스 | 📝 | 📝 |
| 태권도 댄스 | 📝 | 📝 |
| 컵타 난타 | 📝 | 📝 |
| 연극 | 📝 | 📝 |
| 댄스 워십 | 📝 | 📝 |
| 전체 찬양 | (전체) | 전체 |

---

## 4. 연습 운영

- **토요일** — 주 연습일. 팀별로 모여 연습합니다.
- **주일** — **공과 시간을 대체**하여 연습합니다. → [활동 안내 – 분반공부](../활동-안내.md#1-분반공부-공과공부)
- 공연별 음향·소품·동선을 점검하고, 성탄절 전 전체 리허설을 진행합니다.

> 📝 연습 일정표(주차별)를 정해 넣으세요.
