# 초등부 활동 안내

초등부에서 진행하는 활동을 정리한 문서입니다.
예배 순서와 연계되는 부분은 [예배 안내](예배-안내.md) 문서를 함께 참고하세요.

---

## 1. 분반공부 (공과공부)

예배 후 반별로 나누어 말씀을 나누고 적용하는 시간입니다.

| 항목 | 내용 |
| --- | --- |
| 시간 | 예배 후 (약 12:10~12:30) |
| 편성 | 유년부 4개 반, 초등부 4개 반 (담임교사 담당) → [반 편성](운영-안내.md#2-반-편성) |
| 교재 | 하나바이블 |
| 진행 | 담당 교사가 공과 교재로 인도 |
| 목표 | 말씀 복습, 삶의 적용, 교제와 관계 형성 |

**진행 흐름 예시**
1. 인사와 안부 나누기 (아이스브레이킹)
2. 오늘 말씀 요약 복습
3. 공과 교재 질문으로 이야기 나누기
4. 적용과 결단, 마무리 기도

> ⚠️ **월말(마지막 주)에는 앉아서 하는 분반공부 대신**, 그날 공과 내용을 활동적으로 나누는 전체 레크레이션(활동형 공과)으로 진행합니다. → 아래 [5. 월말 활동](#5-월말-활동-마지막-주) 참고
>
> ⚠️ **성탄 연습 기간(11월 셋째 주 ~ 성탄절)에는 주일 공과를 성탄 연습으로 대체**합니다. → [성탄 연습 기획안](기획안/성탄-연습.md)

## 2. 예배 중 진행하는 활동 (광고 시간)

아래 활동들은 예배 마지막 **광고 시간**에 함께 진행합니다. 자세한 순서는 [예배 안내 – 10) 광고](예배-안내.md#5-순서별-상세-안내)를 참고하세요.

| 활동 | 주기 | 내용 |
| --- | --- | --- |
| 생일자 축하 | 월말 1회 | 그달 생일자를 축하 |
| 새신자 축하 | 수시 | 새신자가 있을 경우 소개하고 환영 |
| 암송 | 매주* | 이 주의 암송 말씀 점검 |
| 성경 퀴즈 | 매주* | 주관식 포함 4문제 (주관식 1등에게 추가 달란트) |

\* 암송과 성경 퀴즈는 특별한 일정이 없을 경우 매주 진행합니다.
암송·퀴즈 결과는 달란트로 연결됩니다. → 아래 [4. 달란트 제도](#4-달란트-제도) 참고

## 3. 성경 읽기

연 3회, 회당 8주 과정으로 성경 읽기를 진행합니다. 학생들이 스스로 말씀을 읽는 습관을 기르는 활동입니다.

| 항목 | 내용 |
| --- | --- |
| 횟수 | 연 3회 |
| 기간 | 1회당 8주 과정 |
| 보상 | 완독 시 **20달란트** 지급 |

> 회차별 읽기 범위·일정 등 자세한 내용은 [성경 읽기 기획안](기획안/성경-읽기.md)을 참고하세요.

## 4. 달란트 제도

여러 활동을 통해 달란트를 모으고, 상·하반기 **달란트 잔치**(4월·10월)에서 사용합니다.

**달란트 지급 항목 및 배점**

| 항목 | 달란트 | 내용 |
| --- | --- | --- |
| 출석 | 5 | 예배 출석 |
| 숙제 | 3 | 하나바이블 가정용 교재 |
| 암송 | 2 | 이 주의 암송 |
| 성경책 | 1 | 성경책 지참 |
| 칭찬 | 1 | 교사 칭찬 |
| 퀴즈 | 1 | 주관식 포함 4문제 |
| 퀴즈 주관식 1등 | 2 | 주관식 1등에게 추가 지급 |
| 전도 | 5 | **전도 대상이 3주간 연속 출석할 경우에만 지급** |
| 성경 읽기 | 20 | 8주 성경 읽기 과정 완독 시 (연 3회) → [3. 성경 읽기](#3-성경-읽기) |

## 5. 월말 활동 (마지막 주)

월말 마지막 주는 예배 후 **앉아서 하는 분반공부 대신, 그날 공과 내용을 활동적으로 나누는 전체 레크레이션**으로 진행합니다.

- **생일자 축하** — 그달 생일자를 다 함께 축하
- **전체 레크레이션 (활동형 공과)** — 그날 공과 내용을 기준으로, 앉아서 나누던 공과를 몸으로 활동적으로 나눕니다. (현재 부장이 진행)
  - 준비물은 그날 진행하는 레크레이션에 따라 달라집니다.
