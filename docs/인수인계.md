# 초등부 인수인계 안내

새로 부서를 맡는 분이 **무엇을 넘겨받아야 하는지** 한곳에 모은 문서입니다.
사역의 목표·예배·활동 같은 내용은 다른 문서에 있고, 여기에는 **자료·계정·연락처 같은 실무 인계 사항**을 정리합니다.

> 🔒 **비밀번호는 이 문서에 적지 않습니다.** 실제 로그인 정보는 인계할 때 담당자끼리 직접(또는 비밀번호 관리 도구로) 전달하세요. 여기에는 "무엇을, 누가, 어떻게 넘기는지"만 적습니다.

---

## 1. 자료는 이렇게 넘깁니다

- 초등부의 문서·자료는 **파일로 전달**합니다.
- 현재는 이 **Git 저장소**가 원본이며, 앞으로 **초등부 PC에도 파일로 저장**해 함께 보관·전달할 예정입니다.
- 전체 자료의 소유·관리는 **부장(장충성 집사)**이 맡습니다.

---

## 2. 계정·자산

| 자산 | 소유·관리 | 인계 방법 | 비고 |
| --- | --- | --- | --- |
| 문서·자료 파일 (예배·활동·운영·예산·연간 계획·기획안) | 부장(장충성 집사) | 파일 전달 (현재 Git → 초등부 PC) | 이 저장소가 현재 원본 |
| 웹 교사 가이드 (사이트) | 부장(장충성 집사) | 파일 전달 | `web/` 폴더 |
| 구글 폼 (행사 신청) | 부장(장충성 집사) | 계정·양식 전달 | 보통 3주 전 발송 → 2주 전 집계 |
| 카카오톡 단체방 (전체) | 부장(장충성 집사) | 방장·관리자 위임 | 반별 방은 담임교사가 관리 |
| 구글 스프레드시트 (예산·연간 계획·학생 명단·연락처) | 부장(장충성 집사) | 접근 권한 전달 | 개인정보 포함 — 저장소에는 두지 않음 |

---

## 3. 연락처·명부

- 교사·찬양팀·회계·학생·학부모 **연락처와 학생 명단**은 **구글 스프레드시트(소유: 장충성 집사)**로 관리합니다.
- 개인정보이므로 이 저장소·웹에는 담지 않습니다. 인계할 때 위 시트의 **접근 권한을 함께** 넘겨주세요.

---

## 4. 앞으로 더 채울 것

아직 정리되지 않아, 교회가 채워가면 좋은 인수인계 항목입니다.

- **직분별 업무 달력** — 📝 부장·회계·교역자가 **언제 무엇을** 준비·신청·주문·정산하는지. (예: 여름 성경학교 교재 주문 시기, 노회 사생대회 신청, 구글 폼 발송·집계, 달란트 상품 구매 시기 등)
- **교재·물품·비품** — 📝 하나바이블 주문처·시기·수량, 달란트 상품 구매처, 음향·악기·비품의 위치와 관리 책임.
- **안전·위기 대응** — 📝 비상 연락망, 응급 상황 대응, 알레르기·투약 확인, 아동 보호 관련 기본 지침.
- **외부 거래처** — 📝 노회 교육위, 도시락·버스 업체, 눈썰매장·물놀이장 예약처 등 반복해서 연락하는 곳.
